# 话外前端

以 2026-10-19 用户确认的截图分工为准：亲子沟通翻译、小灯故事、模拟场景练习三个独立入口，相互可跳转。旧产品开发说明书不作为实现依据。

## 本地运行

Node.js 22.12+（本次开发使用 24.21.0）。

```sh
cd frontend
npm ci
npm run dev
```

打开终端输出的本地地址。手机与电脑处于同一局域网时，用电脑局域网 IP 和对应端口访问。生产构建：`npm run build`；输出 `dist/`。本次没有发布公网网站。

## 已实现

- 响应式首页与三个独立功能入口。
- 沟通空间创建／加入界面、按登录身份展示、原话与翻译对照、用户确认、退出和复制邀请码。
- 一篇原创临时示例故事、可选感受与需要问题、设备语音朗读。朗读不是正式故事音频。
- 场景选择、两轮模拟、结束反馈与退出。演示仅开放想念父母场景。
- 小灯使用暖黄色掌心小夜灯形象，配有 CSS 呼吸光效与轻微摇摆，支持减少动态效果偏好。
- 取消、30 秒超时、错误提示、内存会话清理和现实支持提示。

## 演示与真实 API

默认 `VITE_USE_MOCK=true`（未设置也为 true），顶部始终显示“预设演示数据”。沟通示例为只读固定原话；模拟回应和反馈为预设文本，不宣称 AI 理解了任意输入。不连接另一台设备；可退出后以另一个演示身份体验对应页面。

复制 `.env.example` 为 `.env.local`，设置 `VITE_USE_MOCK=false` 后重启开发服务器，进入真实接口模式。`VITE_API_BASE` 默认 `/api`，Vite 开发代理转到 `127.0.0.1:8000`。浏览器端不得配置模型密钥。

**当前 API 是前端建议合同，尚未与后端冻结，真实模式未联调。** 待戴晨羲、周颖提供实际合同后，只在 `src/api/client.ts` 映射路径与响应字段。见 [接口交接](docs/backend-handoff.md)。不要将当前演示当作双端通信或真实 AI 验收完成。

## 素材

`public/static/pet/nightlight-mascot-v2.png` 为内置 imagegen 生成的透明 PNG 掌心小夜灯：暖黄色圆润灯体、深绿色短底座。首页、沟通页、故事页与故事反馈统一通过 `Pet.vue` 使用。旧版台灯 `lamp-mascot-v1.png` 保留备选。生成提示词见 [新形象记录](docs/nightlight-mascot-v2.md)。网页动效为 CSS 微摇摆与呼吸光，不是逐帧角色动画。

故事为前端临时原创示例，待朱瑜玥提供最终内容后替换。会话仅保存在组件内存，离页清空，不写 localStorage，不采集真实个人信息。

## 登录与伙伴选择

先进入登录页，选择孩子或家长。默认本地演示登录，账号和密码为只读预设值，不会验证真实账号。孩子进入五种形象选择，家长直接到首页。右上角头像进入“我的”，可重新选择或退出。

形象采用旧版台灯、小星、小云、小芽、小暖；四个新素材和提示词见 [生成记录](docs/companion-assets.md)。选择 ID 作为本机偏好保存，页面会话不保存沟通内容。演示身份仅在当前标签页保存；真实模式令牌仅保留在内存。真实认证接口未联调，见接口交接文档。

## 身份对应的页面

- 孩子：登录 → 选择伙伴 → 孩子首页（沟通、故事、练习）；右上角可进入我的。
- 家长：登录 → 家长首页（创建／加入亲子沟通）；底部导航为首页、亲子沟通、我的，不展示儿童故事、练习和选形象入口。
- 前端守卫限制家长进入儿童功能路由。真实服务仍须在后端校验用户身份和访问权限。

## 手机对话页

进入沟通空间后采用固定视口聊天布局，只有消息区滚动。停留底部会跟随新消息，查看历史时出现新消息提醒；点击提醒可回到底部。演示工具里可以重复模拟对方来信，验证滚动逻辑。真实轮询结果复用同一展示组件。
